# ⚽ CLEDUN FC - Football Academy Website

A complete football club/academy website built with PHP, MySQL, HTML, CSS, and JavaScript.

## 🏆 Features

### Frontend (User Side)

- **Homepage** - Hero section, gallery slideshow, upcoming matches, latest news, video highlights
- **Squad** - Browse all players with positions, stats, and profiles
- **Teams** - Individual pages for U8, U10, U13, U17, and Senior teams
- **Matches** - Fixtures, results, and live match updates
- **News** - Club announcements, match reports, and transfer news
- **Gallery** - Photo gallery with lightbox viewer
- **Videos** - Upload and watch video highlights (MP4, WEBM, etc.)
- **About** - Vision, mission, and club roadmap
- **Contact** - Contact form with email support
- **Tickets** - Match ticket booking system

### Backend (Admin Panel)

- **Dashboard** - Overview with statistics and quick actions
- **Player Management** - Add, edit, delete players with photos and stats
- **Staff Management** - Manage coaching and support staff
- **Match Management** - Create and manage fixtures with live status
- **News Management** - Publish articles with featured images
- **Gallery Management** - Upload and organize photos for slideshow
- **Video Management** - Upload videos (MP4, WEBM, MOV, etc.)
- **Category Management** - Manage U8, U10, U13, U17, Senior teams
- **Ticket Management** - Configure ticket sections and pricing
- **Booking Management** - View and confirm ticket bookings
- **Message Management** - Read and reply to contact messages
- **Settings** - Configure site details and contact info
- **Backup** - Create and download database backups
- **Password Change** - Secure admin password management

### Interactive Features

- 🤖 **AI Chatbot** - Smart assistant with club knowledge base
- 💬 **WhatsApp Button** - Quick contact for fans
- ⚡ **Live Match Updates** - Real-time score display
- 📸 **Slideshow Gallery** - Auto-playing image slider
- 🎬 **Video Player** - Support for YouTube and uploaded videos

### Security

- 🔐 **Admin Authentication** - Secure login with password hashing
- 🛡️ **Session Management** - Protected admin routes
- 💾 **Database Backup** - One-click backup creation

## 🛠️ Technology Stack

- **Backend:** PHP 7.4+ with PDO
- **Database:** MySQL/MariaDB
- **Frontend:** HTML5, CSS3, JavaScript
- **CSS Framework:** Custom CSS with CSS Variables
- **Icons:** Font Awesome 6
- **Fonts:** Google Fonts (Inter)
- **JavaScript:** Vanilla JS (no frameworks)
